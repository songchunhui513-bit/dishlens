# 点单与点过本地研发计划

日期：2026-06-03

## 目标

在本地实现点单/点过闭环，并保持现网首页、结果列表、菜品详情的主体视觉不变。

## 文件范围

- 修改 `src/types/index.ts`：增加点单/点过类型。
- 修改 `src/lib/local-storage.ts`：增加点过记录存储。
- 新增 `src/lib/order-state.ts`：订单选择、价格解析、记录构建纯函数。
- 新增 `src/components/order/*`：点单控件、详情页底部模块、确认页、点过页、点过详情页。
- 修改 `src/components/home/HomePage.tsx`：底部导航新增点过。
- 修改 `src/components/results/ResultsPage.tsx`：卡片新增轻量选择控件。
- 修改 `src/components/dish/DishDetailPage.tsx`：底部新增点单模块。
- 修改 `src/app/page.tsx`：接入状态、导航和评价回流。
- 修改 `tests/logic-regressions.test.mjs`：先补失败测试，再实现。

## 执行步骤

1. 写失败测试：覆盖点单数量、价格摘要、本地存储 key、UI 接入边界。
2. 运行测试，确认失败点来自缺失实现。
3. 增加类型和纯函数，使逻辑测试通过。
4. 增加本地存储读写和标记已评。
5. 增加订单组件，使用现网 token 和轻量样式。
6. 接入首页底部“点过”入口。
7. 接入结果列表选择控件。
8. 接入菜品详情底部点单模块。
9. 接入点单确认、点过、点过详情页面。
10. 运行测试和 lint。
11. 启动本地服务，按 393px 视口自检关键页面。
12. 给用户本地演示地址，不发布现网。

## 自检清单

- 首页主体未增加中部点过卡片。
- 结果列表没有新增顶部摘要或“几道菜品”。
- 菜品详情正文结构未重做。
- 点单模块没有挡住详情页评价按钮。
- 点单确认页的卡片颜色轻，不使用重橙。
- 保存按钮不过重。
- 点过页无分享、无点过次数 badge。
- 点过详情卡片与翻译列表风格一致。
- 价格未知时显示待核对。
- 评价完成后能回到点过详情并显示已评。
