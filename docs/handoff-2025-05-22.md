## 关键技术决策

### 1. 为什么从 Vercel 迁移到阿里云 ECS
- Vercel Serverless 在响应返回后杀进程，后台 `processImages()` 被终止
- 60s maxDuration 对大菜单不够
- ECS 无超时限制

### 2. 翻译 API 的异步设计
- `POST /translate/menu` → 返回 `202 { task_id }`
- 前端 LoadingPage 轮询 `GET /task/[id]` 获取进度
- 后台异步处理完成后更新任务状态
- 任务存储：内存 Map（单实例够用，Upstash Redis 未配置）

### 3. File 对象生命周期修复
- **问题**：后台处理时 File 的 body stream 已关闭
- **修复**：响应返回前预读所有 File 的 arrayBuffer 到内存
- **文件**：`src/app/api/v1/translate/menu/route.ts`

### 4. Qwen VL Prompt 简化
- **问题**：42 道菜 × 7 字段 → JSON 超过 max_tokens 被截断
- **修复**：只要求 4 个核心字段（name_original、name_translated、description、confidence），其余在代码里设默认值
- **文件**：`src/lib/ai/qwen.ts`

### 5. 大菜单优化
- 超过 10 道菜时跳过逐道 `refineTranslation()`
- 客户端图片压缩：maxDim=1500, quality=0.75
