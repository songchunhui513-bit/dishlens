# DishLens 全球菜单分享需求

日期：2026-05-27

## 背景

现有方案 A 原型已经验证了“把一份菜单结果转成可分享链接”的方向。下一步需要把它接入真实结果页和 `/share/[id]`，并从单一微信群场景扩展到全球常见分享场景。

国内用户通常会把链接发到微信好友、微信群或朋友圈；海外用户更常用 WhatsApp、Telegram、LINE、Facebook、X 以及手机原生分享菜单。因此分享能力不能依赖微信私有协议，也不能把“微信群”作为唯一入口。

## 目标

1. 结果页完成识别后，可以直接打开统一分享面板。
2. `/share/[id]` 公开页可以再次转发，形成二次传播。
3. 分享面板覆盖国内与海外主流渠道：发给朋友、复制链接、微信、WhatsApp、Telegram、LINE、Facebook、X。
4. 分享链接带有动态标题、摘要和 Open Graph 元数据，适配聊天软件预览卡片。
5. 微信内置浏览器中，微信入口和“发给朋友”优先打开微信好友转发；微信外不使用不可控私有 deep link，失败时复制链接兜底。
6. 分享图标采用 DishLens 自有 warm editorial 插画体系，不使用系统分享箭头、文字缩写或不协调的品牌硬色块。

## 用户场景

### 国内聚餐

用户在餐厅拍菜单识别后，把结果发到微信群。群友打开 `/share/[id]` 后能看到菜品、价格、翻译和推荐理由，再自行选择。

成功标准：微信内点击“发给朋友”或“微信”不会进入 iOS 系统分享扩展卡住，而是走微信好友转发；桥接不可用时复制链接并给出强提示。

### 海外旅行

用户在海外餐厅识别菜单后，通过 WhatsApp 或 Telegram 发给同行者。接收者打开链接后不需要登录即可查看菜单结果。

成功标准：WhatsApp、Telegram、LINE 链接能带上标题、摘要和 URL，点击对应 App 按钮直接跳到对应分享页或 App。

### 跨设备保存

用户希望稍后在电脑或另一个手机上看菜单，通过复制链接或手机原生分享菜单保存链接。

成功标准：复制链接有面板中央强提示；iOS 系统分享面板展示 DishLens 插画风图标和分享预览图；原生分享即使被目标 App 忽略 `url` 字段，文本里也包含完整链接。

### 二次转发

接收者从 `/share/[id]` 页面继续转发给其他人。

成功标准：公开分享页与原结果页复用同一套分享交互，文案和链接一致。

## 功能范围

本期包含：

- 结果页分享按钮接入统一分享面板。
- `/share/[id]` 分享页接入统一分享面板。
- 分享链接和渠道 URL 生成逻辑抽成复用模块。
- 动态页面 metadata、Open Graph、Twitter summary、iOS Apple touch icon 和分享预览图。
- 全球渠道 UI 和成功/失败反馈。
- 回归测试覆盖链接生成、元数据和 UI 接线。

本期不包含：

- 多人协同点菜状态同步。
- 私有群成员权限管理。
- 微信 JS-SDK 签名配置、公众号票据刷新、服务端签名接口，以及从微信外普通浏览器直接打开微信好友选择器。
- 分享数据埋点看板。

## 验收标准

1. 结果页点击“分享菜单”会打开分享面板。
2. `/share/[id]` 点击“分享给朋友”会打开同一分享面板。
3. 分享面板包含发给朋友、复制链接、微信、WhatsApp、Telegram、LINE、Facebook、X。
4. 微信内置浏览器中，微信按钮和“发给朋友”不走 `navigator.share`，改走 `WeixinJSBridge.invoke("sendAppMessage")`；微信外不可桥接时复制链接并提示。
5. 分享 URL 使用 `/share/{taskId}`。
6. `/share/[id]` 能生成与具体菜单相关的 title、description、openGraph 和 canonical。
7. `node --test tests/logic-regressions.test.mjs`、`npm run lint`、`npm run build` 通过。
8. app/link/PWA 图标使用方案 C「一起看菜」：聊天气泡 + 餐碗 + 暖色手绘描边。
9. 分享面板主文案包含“朋友不用登录，点开就能一起看菜”，按钮说明包含“发到聊天里一起看菜”和“适合粘到任何群聊”。
10. `/apple-touch-icon.png`、`/icons/apple-touch-icon.png` 和 `/icons/share-preview-20260527.png` 均可访问，iOS 分享预览不再回退到灰色系统罗盘。
11. 分享面板顶部摘要图标使用菜单插画，不与微信渠道图标重复。
12. 复制成功、复制权限失败、微信桥接失败、App 打开中等状态必须在面板中央展示明显 toast。
