# DishLens 智能推荐 + 历史 + 收藏 — 需求文档

> 版本：v1.0 | 日期：2026-05-23
> 前置条件：无用户登录体系，所有数据存 localStorage
> 设计规范：v7 Warm Editorial

---

## 用户故事

### US-011 智能每日推荐

**作为** DishLens 用户
**我希望** 打开首页时看到基于当前时间、天气、地区的菜品推荐
**以便** 在不熟悉的餐厅环境中获得点菜灵感

**验收标准：**
- [ ] 首页 hero 卡片显示推荐菜品的名称（中英双语）、菜系标签、图片
- [ ] 推荐基于时段自动调整（早餐/午餐/下午茶/晚餐）
- [ ] 天气信息可获取时，推荐适配天气的菜品（冷天推汤/炖，热天推沙拉/甜品）
- [ ] 地理位置可获取时，推荐当地菜系
- [ ] 天气/定位获取失败时，降级为纯时间+随机推荐，不报错不崩溃
- [ ] 同一天打开 app 看到同一道菜，次日自动换
- [ ] 推荐菜品来自 1022 道知识库，显示知识库中的描述和图片
- [ ] hero 卡片点击可进入菜品详情页
- [ ] 数据来自菜品知识库（`dishKnowledgeDb`），无需网络请求

**优先级**：P1
**技术备注**：纯客户端运算，无后端依赖

---

### US-012 翻译历史

**作为** DishLens 用户
**我希望** 在历史页面查看所有翻译记录
**以便** 回顾之前翻译过的菜单和菜品

**验收标准：**
- [ ] 翻译完成后自动记录到历史（无需手动操作）
- [ ] 历史页按月分组显示所有翻译记录
- [ ] 每条记录显示：第一道菜缩略图、餐厅名、城市名、菜品数量、翻译日期
- [ ] 历史数据存储在浏览器 localStorage，不依赖后端
- [ ] 最多保留 100 条记录（超出自动淘汰最旧的）
- [ ] 无历史时显示空状态引导文案
- [ ] 首页「最近翻译」区显示最近 3 条历史记录
- [ ] 数据持久化，关闭浏览器重开仍保留

**优先级**：P1
**技术备注**：localStorage 存储，key: `dishlens_history`

---

### US-013 收藏菜品

**作为** DishLens 用户
**我希望** 在菜品详情页收藏感兴趣的菜，在收藏页面统一管理
**以便** 下次快速找到想吃的菜

**验收标准：**
- [ ] 菜品详情页心形按钮可点击，切换收藏/取消收藏
- [ ] 收藏状态在详情页、收藏页之间同步
- [ ] 收藏页显示所有已收藏菜品（缩略图 + 名称 + 菜系）
- [ ] 收藏页点击菜品可进入详情页
- [ ] 收藏页可移除收藏（点击心形图标）
- [ ] 数据存储在浏览器 localStorage，不依赖后端
- [ ] 无收藏时显示空状态引导文案
- [ ] 数据持久化，关闭浏览器重开仍保留

**优先级**：P1
**技术备注**：localStorage 存储，key: `dishlens_favorites`

## 非功能需求

| 需求 | 指标 |
|------|------|
| 推荐加载速度 | < 200ms（纯本地计算） |
| 天气 API 超时 | 3 秒，超时降级 |
| 定位 API 超时 | 5 秒，超时降级 |
| localStorage 容量 | 历史约 50KB/100条，收藏约 20KB |
| 优雅降级 | 天气/定位失败不影响核心功能 |

## 范围外（Out of Scope）

- 用户登录 / 账号体系
- 跨设备数据同步
- 推荐算法学习用户口味偏好（需登录后实现）
- 收藏夹分类/分组
- 历史记录搜索
